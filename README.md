# Recipe Finder 🍳

A simple Flutter Recipe Finder app created for an internship project.

## Features
- Recipe search
- Recipe categories
- Recipe cards with images
- Ingredients and cooking instructions
- Responsive Material 3 UI

## Run locally

```bash
flutter pub get
flutter run
```

## Project structure

- `lib/main.dart` — complete application UI and recipe data
- `pubspec.yaml` — Flutter project configuration
